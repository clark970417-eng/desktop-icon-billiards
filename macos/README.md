# 桌面图标台球 · Mac

Mac 版本 v0.4.0，支持 macOS 13 以上，默认简体中文，可切换英文。由 Swift 与 AppKit 实现，保留[原作者 LXG 的 Windows 版本](https://github.com/liuxiaogang-com/desktop-icon-billiards)及 MIT 授权。

## 开始游戏

双击 `Desktop Icon Billiards.app`。普通窗口优先使用 `/Applications` 中的 15 个 App 图标，也可从菜单“游戏 → 选择图标文件夹…”使用文件图标和图片缩略图。

从菜单“游戏 → 桌面开局／退出还原”进入桌面模式，允许 macOS 询问的 Finder 自动化权限后，主屏幕的桌面图标会从原位进入球桌。程序优先选择 App、快捷方式，再选择文件、文件夹；球数为 15–45，不足 15 个时只在游戏中复制补球，不创建文件。为限制读取量，单次最多捕获 Finder 返回的前 512 个项目，再从主屏幕可用区域中选择。

按住鼠标左键蓄力，松开击球。力度在 0%–100% 间循环，1.5 秒升满、1.5 秒降回；短按可轻推。白球落袋后会自动寻找空位，必要时可点击球桌手动放置。

点击工具栏“退出”、按 `Esc`、`⌘Q` 或全局快捷键 `⌘⌥X`，桌面球局会先播放图标归位动画再退出。若全局快捷键被其他 App 占用，界面会提示使用 `Esc` 或退出按钮。

## 台面、工具栏与瞄准

台面采用原版的壁纸模糊、薄荷绿细边与六个圆形洞口；图标保留原本形状，白球与自定义纹理使用原版球面光照，球杆采用木色握柄与蓝色杆头。洞口半径为本局最大碰撞球半径的 1.20 倍；实际入袋圈位于洞口内，辅助线和运动共用同一判定。

辅助线的白线表示首次接触，蓝线表示白球碰撞或反弹后的方向，绿线表示被撞图标的方向；三种虚线会按壁纸明暗切换配色，并显示接触圈、目标圈和终点圈。接触圈使用真实碰撞半径。路线不代表实际滚动距离，能否到达仍取决于力度。

关闭“台面”后，球袋改为系统废纸篓图标，工具栏在鼠标移开一秒后收起。移到工具栏原位置的小眼睛可恢复；按住 `Shift` 临时显示球杆和辅助线。这个开关不会重开球局。

工具栏沿用原版的功能分组、配色与两行布局；窄窗口下自动换行。拖动左侧手柄或数据区可移动工具栏，位置会保存。文件来源、暂停与语言等 Mac 菜单位于屏幕顶部的“游戏”菜单；“游戏 → 语言”可切换简体中文与英文。切换会立即刷新工具栏及已打开的白球设置、成绩卡、排行榜、打赏和更新窗口，不重置球局或图片选择。

| 按键 | 功能 |
| --- | --- |
| `R` | 重新开始 |
| `G` | 切换辅助线 |
| `T` | 切换台面 |
| `Space` | 暂停／继续 |
| `Shift` | 隐藏台面时临时显示辅助 |
| `Esc` / `⌘Q` | 退出并还原桌面 |
| `⌘⌥X` | 全局退出（注册成功时） |

切换 App、锁屏或休眠会取消蓄力并暂停已开始的球局。屏幕布局、分辨率等配置变化时，桌面球局会停止并恢复普通窗口，避免继续使用旧坐标。同一用户只能运行一个新版实例。

## 图片缩略图与白球外观

PNG、JPEG、HEIC 等可读取的本机图片会在后台生成各自的缩略图，保留比例与方向，单张缩略图最多 256 像素。无法读取、损坏或尚未下载的 iCloud 图片会保留文件图标；游戏不会自动下载云端原图。系统可能另行询问桌面文件读取权限。

“白球外观”可选择图片，通过拖动、滚轮或滑块调整圆形裁切，再点击使用。只保存处理后的 256 像素纹理，不保存来源路径；下次启动自动加载，也可恢复默认白球，不改变碰撞与力度。输入图片限 20 MB、2500 万像素，以避免大图阻塞游戏。

## 计时、成绩卡与排名

计时从第一杆开始，到最后一个图标落袋为止，内部保留毫秒精度，界面沿用 Windows 的百分之一秒格式，并显示每颗平均用时、杆数和本机最佳。清台后显示 1080×1350 成绩卡，版式、段位颜色、全球名次、进度条、四列数据与署名均按当前 Windows 源码绘制。可使用系统保存面板导出 PNG、点击复制图片，或再来一局。卡片只有成绩与作者署名，没有桌面缩略图、文件名或路径。

全球排名**默认关闭**。打开排名窗口只显示说明，不会联网。只有你点击工具栏“排名”或在排行榜中勾选启用后，才会向原版排名服务发送匿名设备标识、球数、用时与杆数，使用与 Windows 相同的签名协议。不会上传桌面文件或图像。局中启用时，从下一局开始提交；离线或请求失败不影响游戏，关闭排名会取消待处理请求。

排行榜与真实段位只使用服务返回的数据，不凭本机成绩虚构全球名次。客户端协议已通过拦截请求的模拟服务验证；真实 Mac 成绩是否被线上服务接受，仍需主动启用后的实测，不由模拟测试代替。

## 桌面、隐私与当前限制

桌面模式用当前壁纸的静态图片覆盖原始图标，再绘制游戏副本。Finder 文件、位置和设置始终保留；正常退出或进程意外结束后，覆盖窗口消失，原桌面即重新显示。不会修改壁纸、隐藏 Finder 图标或重启 Finder，也不需要屏幕录制、辅助功能或完全磁盘访问权限。

仅在本机读取桌面项目、图片内容和位置。图标与来源路径不写入发行包、日志或成绩卡。白球纹理、本机最佳、语言偏好及主动启用后的排名凭据保存在本机应用数据目录。程序不会启动所选 App。

目前只在主屏幕开局。动态／视频壁纸只使用可读的静态图像；无法读取时显示错误并保留普通窗口。Finder 堆叠的显示方式、真实多屏插拔、旧版 macOS 与 Intel 实机仍需分别验证。游戏期间从其他地方改变的桌面文件与排列会保留，游戏图标在下次开局重新读取。

这是使用本机 ad-hoc 签名的预览版，尚未经过 Developer ID 签名与 Apple 公证。“打赏”保留原作者赞赏图片；“关于桌面图标台球”保留署名、授权与 Mac 下载入口。“检查更新”只在点击时读取此 fork 的 GitHub Releases，筛选兼容的 Mac ZIP；可打开发布页面，不会自动下载或执行文件。当前没有已发布的 Mac 安装包，界面会如实显示这一状态。

## 构建与验证

安装 Xcode Command Line Tools，Swift 5.9 以上；完整 XCTest 套件另需完整 Xcode。

```sh
bash macos/check.sh
bash macos/check-desktop.sh
bash macos/check-artwork.sh
bash macos/check-applications.sh
bash macos/check-parity.sh
bash macos/check-presentation.sh
bash macos/check-ranking.sh
bash macos/check-update.sh
bash macos/check-ball-artwork.sh
bash macos/check-information.sh
bash macos/check-session.sh
bash macos/build.sh --universal
open "macos/dist/Desktop Icon Billiards.app"
```

产物为 `macos/dist/DesktopIconBilliards-0.4.0-macOS-universal.zip`，含 Apple Silicon 与 Intel 可执行文件；交叉编译不等于两种机器都完成实测。默认 `bash macos/build.sh` 只构建本机架构。

模拟测试使用生成的图片、Finder 数据和不可见窗口；排名与更新测试拦截全部请求，不会提交测试成绩。Applications 检查读取本机 App 图标并核对来源未变动，不启动它们。`check-session.sh` 注入默认关闭、隔离存储的排名控制器，避免读取用户的启用状态后意外联网。

原始 Windows 测试中的可移植部分可另行验证：

```sh
uv run --no-project --python 3.12 --with Pillow==13.0.0 python macos/check-windows-portable.py
```

此脚本明确列出不在 Mac 执行的五个 Windows 专属方法；完整 Windows 套件与 EXE 构建由独立 CI 执行。原版工具栏测试的旧单行预期已校正为当前两行布局与白球按钮；未修改 Windows 实现，也未跳过测试。完整 Xcode 环境也可执行 `swift test --package-path macos`。

[功能差距、测试证据与原作者合并要求](../docs/macOS-parity-review.md)记录了实现状态与待验证项。通过本机测试不能保证上游合并；决定仍由原作者作出。
