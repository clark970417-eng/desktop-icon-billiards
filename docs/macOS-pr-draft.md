# feat: 添加接近 Windows 原作的 macOS 桌面台球支持

## 问题与范围

上游 [issue #9](https://github.com/liuxiaogang-com/desktop-icon-billiards/issues/9#issuecomment-6853106839)记录了 Mac 支持不足及需要更多测试的问题。此变更在 `macos/` 中新增 Swift 与 AppKit 实现，按 Windows v0.2.4 的提交 [`5d1bb4ce1d18b6791d16ae98ce0d1ad6a663252d`](https://github.com/liuxiaogang-com/desktop-icon-billiards/commit/5d1bb4ce1d18b6791d16ae98ce0d1ad6a663252d)保留随开随玩的单人玩法；Windows 源码、测试、依赖与原构建脚本不变。

界面与交互按当前 Windows 源码还原，包括紧凑工具条、按钮配色、模糊壁纸、长木质球杆、原图标，以及当前四列统计的成绩卡。局域网 PR #7 尚未合并，此变更不引入双人规则。

## 行为

- 读取 Finder 图标位置与本机图片缩略图，从原位进入球局；保留原文件、桌面排列和设置。退出时播放归位动画并移除覆盖层，异常退出也不需要改写 Finder 来恢复桌面。
- 按程序或快捷方式、文件、文件夹的顺序选择 15 至 45 颗球，不足时仅在游戏画面复制补球。普通窗口优先使用 `/Applications` 的 15 个 App 图标试玩。
- 提供蓄力、碰撞、反弹、六袋、白球复位、首次接触及碰撞后辅助线、入袋动画、隐藏台面和 Shift 临时辅助。袋口与捕捉圈按物理球尺寸同步设置，避免球和袋口尺寸不匹配。
- 成绩卡使用原作标志、标题、段位颜色、全球排名、百分位条、四列统计及作者署名；仅显示真实排名数据，支持保存、复制、再来一局和查看排行榜。白球图片支持拖动、缩放、裁切和本机保存。
- 默认简体中文，英文可由菜单切换。更新最终状态文字后再计算布局，保留球局、排名和已选图片状态。排名需主动开启；Mac 更新检查使用自己的发行渠道，不替换运行中的文件。

## 验证

本轮 197 项本机检查通过：物理 27、桌面与壁纸 29、布局和平台状态 20、成绩与裁切 18、排名模拟 16、更新模拟 16、缩略图 10、球面绘制 5、实际 App 图标 7、会话集成 38、打赏与关于 11。另有原 Windows 测试中的 94 项可移植方法通过。Universal 包的两种架构和本地签章已核对。

先前打包版本在 Apple Silicon Mac 上实际验证过中英文切换，切换后仍保留 12 杆、4 颗入袋的状态。最终 GameView 离屏画面和成绩卡已检查；可见 UI 工具无法读取旧进程窗口，尚未以重启结束用户球局。生成数据和模拟请求不等于多设备或线上服务验证。

新增 Mac 与 Windows CI 检查配置。Windows 工作流将执行完整原测试，再使用原 `build.ps1` 生成 EXE；目前尚未取得实际运行结果。旧 Mac CI 因未分配到托管运行器而没有执行任何步骤，不能作为代码构建失败或成功的证据。详细命令、原作者审查要求与验证边界见 [功能对照及合并审查](macOS-parity-review.md)。

## 限度与合并前确认

仍需验证最终打包界面、Intel Mac、macOS 13、Retina 与真实多屏切换、锁屏唤醒、显示器拔插、动态壁纸和 Finder 堆叠。通用包中的两种架构不能替代两种硬件的实际运行；排名协议模拟不能证明线上服务接受真实 Mac 成绩。Developer ID 签署、公证与独立设备下载启动也尚未完成。

[PR #12 的语言审查](https://github.com/liuxiaogang-com/desktop-icon-billiards/pull/12#pullrequestreview-5920304505)用于检查最终标签、工作区边界、已打开窗口刷新及状态保留；它针对的是该国际化 PR，不能据此宣称上游已接受 Mac 实现。[PR #7 的回复](https://github.com/liuxiaogang-com/desktop-icon-billiards/pull/7#issuecomment-6858043124)保留了轻量单人方向，本变更沿用这个范围。合并决定仍由维护者作出。
